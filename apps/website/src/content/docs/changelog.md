새 버전이 나오면 위에 추가해요. 날짜는 한국 시간 기준이에요. 각 버전의 전체 커밋은 [GitHub 릴리스](https://github.com/RanolP/chan-necessity/releases)에서 볼 수 있어요.

## 0.7.1 (2026-10-08)

### 수정

- 스플릿 뷰에서 넓은 화면 모드를 켜면 플레이어 조작 바와 자막이 영상 아래로 밀려나던 문제 수정

## 0.7.0 (2026-10-08)

### 기능 추가

- 라이브 페이지를 기본으로 칸 1개짜리 [스플릿 뷰](/chan-necessity/features/split-view/)로 열기
- 스플릿 뷰가 창 폭에 맞춰 배치를 바꿈: 900px 이상이면 채팅을 옆에, 미만이면 아래에 표시하고, 칸이 320px보다 좁아지면 가로 스크롤로 넘김

### 수정

- 스플릿 뷰 첫 칸에 치지직 헤더가 겹쳐 보이던 문제 수정

## 0.6.1 (2026-10-07)

### 기능 추가

- [실시간 자막](/chan-necessity/features/subtitles/)에서 1.7B 모델과 함께 더 가벼운 0.6B 모델도 WebGPU 엔진으로 실행
- 모델 파일을 받지 못했을 때 오류에 파일 이름, 주소, 원인을 함께 표시

## 0.6.0 (2026-10-07)

### 기능 추가

- 플레이어 하단 바에 기능 버튼을 한곳에 모아 표시
- [실시간 자막](/chan-necessity/features/subtitles/)을 자체 WebGPU 인코더와 음성 감지(VAD)로 실행
- 지난 자막을 방송 시각과 함께 보여 주는 자막 기록 창
- 앞선 구간을 재사용하고 최근 24초 오디오를 문맥으로 쓰는 스트리밍 자막
- 탐색(seek)을 감지해 자막 오디오 캡처를 다시 맞춤
- [스플릿 뷰](/chan-necessity/features/split-view/)에서 칸 위치에 따라 화면 이동 범위를 제한

### 수정

- 같은 문장을 반복해서 내놓던 자막 루프 해결
- 말이 7초 넘게 없으면 이전 자막을 이어 붙이지 않고 새 자막으로 시작
- 오래 멈췄다가 다시 나온 자막이 직전 문장과 어긋나던 문제 수정
- 글자 중간에서 자막이 잘리던 문제 수정
- 1초가 안 되는 짧은 오디오 조각에서도 자막이 바로 시작되도록 수정
- 탐색 직후 생기는 버퍼링 때문에 자막이 멈추던 문제 수정
- 프레임 드롭이 잦을 때 자막 처리 속도 조절을 개선하고, 처리 속도도 향상
- 한 페이지에 스크립트가 두 개 설치돼 있어도 하나만 실행 (버튼 중복, 자막 엔진 중복 실행 방지)
- 플레이어 하단 바 버튼과 [북마크](/chan-necessity/features/bookmarks/) 패널이 기본 컨트롤과 함께 사라지도록 수정
- 실시간 자막 줄을 왼쪽 정렬

## 0.5.0 이전

이 저장소는 0.5.0 상태의 유저스크립트를 옮겨 와 시작했어요. 0.5.0까지의 [화질](/chan-necessity/features/deny-grid/), [스플릿 뷰](/chan-necessity/features/split-view/), [북마크](/chan-necessity/features/bookmarks/), [통나무 파워](/chan-necessity/features/auto-claim-logs/), [실시간 자막](/chan-necessity/features/subtitles/)은 각 기능 페이지에 정리돼 있어요.
