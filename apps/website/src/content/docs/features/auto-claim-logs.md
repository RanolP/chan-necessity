라이브 채팅창에 통나무 파워 받기 버튼이 뜨면 chan-necessity가 대신 눌러요. 이 부분은 「치지직 통나무파워 자동 벌목」 v1.7.1(떱_, MIT)과 Cheese Spanner를 참고했어요.

## 화면의 버튼만 눌러요

받기는 언제나 화면에 보이는 버튼을 누르는 방식으로만 해요. 치지직 API를 직접 부르지 않아요. 그래서 사람이 버튼을 누른 것과 같은 경로로 처리돼요.

## 어떤 버튼을 누르나요

아래 조건을 모두 만족하는 버튼만 눌러요.

- 채팅 영역(`#aside-chatting`) 안에 있어요.
- 글자에 「통나무 파워」가 들어 있고, 「1,000개 받기」나 「500 받기」처럼 숫자와 「받기」가 함께 있어요.
- 화면에 보이고, 비활성 상태가 아니에요.
- 랭킹 버튼이나 펼치기·드롭다운 버튼이 아니에요. 그런 버튼은 일부러 건너뛰어요.

## 타이밍

- 페이지 내용이 바뀌면 0.25초 뒤에 채팅창을 훑어요.
- 버튼을 찾으면 0.12초 기다렸다가 눌러요. 버튼이 자리를 잡을 시간을 주는 거예요.
- 같은 버튼은 10초 안에 다시 누르지 않아요. 눌렀는데 버튼이 그대로 남아 있으면 10초 뒤에 한 번 더 시도해요.

## 눌렀는지 확인하기

버튼을 누를 때마다 브라우저 콘솔에 `chan-necessity·auto-claim-logs 통나무 파워 claimed:`가 붙은 줄과 버튼 글자가 남아요. 이 줄은 누른 기록이라, 받기가 실제로 됐는지는 화면의 통나무 파워 수치로 확인해 주세요. 화면에는 따로 알림을 띄우지 않아요.
