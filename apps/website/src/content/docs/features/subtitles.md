---

실시간 자막은 방송 소리를 브라우저 안에서 바로 받아 적어 플레이어 위에 띄워요. 음성 인식은 Qwen3-ASR 모델을 WebGPU로 돌리고, 말소리 구간은 Silero VAD로 가려내요. 소리는 외부 서버로 보내지 않아요.

## 켜기

기본값은 꺼짐이고, 켜기 전에는 모델을 받지 않아요.

- 플레이어 버튼 줄의 「실시간 자막」 버튼을 누르면 켜지고, 한 번 더 누르면 꺼져요. 켜져 있으면 아이콘이 초록색이에요.
- 플레이어 설정(톱니바퀴) 메뉴의 「자막」 → 「실시간 자막」 토글로도 켜고 끌 수 있어요.

켠 상태는 저장돼요. 다음에 페이지를 열면 화면을 한 번 클릭하거나 키를 누른 뒤에 자막이 다시 시작돼요. 브라우저가 사용자 동작 없이는 오디오 처리를 시작하지 못하게 막기 때문이에요. 그동안 「화면을 한 번 클릭하면 자막이 시작돼요」가 떠요.

## 처음 켤 때 받는 파일

처음 켜면 모델 파일을 받아요. 1.7B 모델은 약 1,859 MB예요. MB는 진행 표시와 같은 단위(1 MB = 1,048,576 바이트)예요.

여기에 말소리 감지 모델(Silero VAD) 약 2.2 MB가 더해져요. 받는 동안 「1.7B 모델 다운로드 N% (a/b MB)」처럼 진행률이 떠요.

받은 파일은 브라우저 Cache Storage의 `chzzkbest-stt-v1`에 저장돼요. 두 번째부터는 다시 받지 않고 「1.7B 캐시에서 불러오는 중 N%」로 불러와요. 브라우저가 이 캐시를 함부로 지우지 않도록 영구 저장소도 요청해요. 중간에 끊겨 덜 받아진 파일은 다음에 다시 받아요.

## 필요한 환경

WebGPU가 되는 브라우저가 필요해요. 안 되면 자막 자리에 이런 오류가 떠요.

- `자막 오류: Error: WebGPU 없음 (navigator.gpu undefined)`: 브라우저에 WebGPU가 없어요.
- `자막 오류: Error: WebGPU 어댑터 없음`: WebGPU는 있지만 쓸 수 있는 GPU를 찾지 못했어요.

Firefox도 지원해요. Firefox의 WebGPU 구현 차이를 맞추는 보정이 들어 있어요. Chrome에서는 영상 스트림에서 소리를 따기 때문에 음소거, 볼륨, [좌우 밸런스](/chan-necessity/features/split-view/#좌우-밸런스)와 상관없이 자막이 돌아요. Firefox에는 그 방법이 없어서 플레이어 소리를 좌우 밸런스 앞에서 가져와요. 그래서 Firefox에서는 플레이어를 음소거하거나 볼륨을 0으로 하면 자막도 멈춰요.

인코더, 디코더, 말소리 감지(Silero VAD)가 모두 전용 WebGPU 엔진 위에서 돌아요. onnxruntime은 쓰지 않아요. 엔진은 GitHub 릴리스의 `manifest.json`, `qknorm.bin`과 모델 파일을 쓰고, GPU의 `shader-f16` 지원 여부와 상관없이 같은 파일로 돌아요.

## 자막 설정

플레이어 설정(톱니바퀴) 메뉴의 재생 속도 아래에 「자막」 줄이 생겨요. 켜져 있으면 글자 크기가, 꺼져 있으면 「끔」이 옆에 나와요. 누르면 「자막 설정」 화면이 열리고, `Esc`나 `Backspace`로 돌아가요.

- 「실시간 자막」: 켜고 꺼요.
- 「글자 크기」: 작게 · 보통 · 크게 · 아주 크게. 기본은 보통이에요.
- 「배경」: 없음 · 반투명 · 기본 · 불투명. 기본은 기본이에요.
- 「위치」: 아래 · 위. 기본은 아래예요.
- 「모델」: 「1.7B (기본)」 · 「0.6B」. 켜진 상태에서 바꾸면 새 모델로 다시 시작해요. 엔진이 1.7B용이라 「0.6B」는 아직 불러오지 못해요.
- 「캐시 삭제 (N MB)」: 받아 둔 모델 캐시(`chzzkbest-stt-v1`)를 지워요. 다음에 켜면 다시 받아요.

## 화면에 나오는 것

- 자막은 6초 길이의 소리 조각 단위로 받아 적어요. 아직 확정되지 않은 글자는 흐리게 보여요.
- 새 글자가 7초 동안 없으면 자막이 사라져요.
- 자막 위의 작은 숫자(예: `1.4s`)는 지연 표시예요. 그 소리 조각을 모델에 보낸 순간부터 글자가 화면에 나오기까지 걸린 초예요. 자막이 비어 있으면 숨어요.

## GPU 오류가 나면

GPU 장치를 잃으면(드라이버 재시작 등) `자막 오류: GPUDeviceLost: …`가 뜨고 자막이 멈춰요. 이때는 자동으로 다시 시도하지 않아요. 다시 시도하다가 드라이버 재시작이 반복되는 걸 막기 위해서예요. 그 밖의 로드 오류도 `자막 오류: <원인>`을 띄우고 같은 방식으로 멈춰요. 자막을 끈 뒤 다시 켜면 처음부터 새로 시작해요.

인식 도중 오류는 두 번까지 넘기고, 세 번 연속으로 나면 멈춰요.

## 스플릿 뷰에서

[스플릿 뷰](/chan-necessity/features/split-view/)에서는 맨 왼쪽 칸에서만 자막이 돌아요. 모델은 바깥 페이지에서 한 번만 불러와 칸들이 같이 써요. 자막을 쓰는 칸이 15초 동안 없으면 모델을 내려요.
