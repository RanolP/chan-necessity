<Aside type="note" title="먼저 Violentmonkey가 필요해요">
chan-necessity는 유저스크립트예요. 브라우저에 [Violentmonkey](https://violentmonkey.github.io/) 확장을 먼저 설치한 뒤 「스크립트 설치」를 누르면 설치 화면이 열려요. 자세한 순서는 [설치 안내](/chan-necessity/install/)에 있어요.
</Aside>

## 기능

<CardGrid>
  <Card title="1080p 화질" icon="laptop">
    치지직이 요구하는 조건 때문에 막힌 1080p 화질을 고를 수 있게 해요. [자세히](/chan-necessity/features/deny-grid/)
  </Card>
  <Card title="통나무 파워 자동 수집" icon="star">
    채팅 옆에 뜨는 통나무 파워 받기 버튼을 대신 눌러 줘요. [자세히](/chan-necessity/features/auto-claim-logs/)
  </Card>
  <Card title="라이브 북마크와 다시보기 타임라인" icon="pencil">
    라이브를 보다가 순간을 표시해 두고, 다시보기에서 그 지점으로 바로 이동해요. [자세히](/chan-necessity/features/bookmarks/)
  </Card>
  <Card title="실시간 자막" icon="comment">
    방송 소리를 브라우저 안에서 바로 받아써서 자막으로 보여 줘요. 음성 인식 모델은 WebGPU로 내 컴퓨터에서 돌아요. [자세히](/chan-necessity/features/subtitles/)
  </Card>
  <Card title="스플릿 뷰" icon="desktop">
    여러 채널을 한 화면에 나란히 띄우고, 칸마다 소리를 왼쪽·오른쪽으로 나눠 들어요. [자세히](/chan-necessity/features/split-view/)
  </Card>
</CardGrid>
